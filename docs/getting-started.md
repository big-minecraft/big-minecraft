# Getting Started

Clone this repository using [git](https://git-scm.com/install/mac) into a safe, permanent location.
```sh
git clone https://github.com/big-minecraft/big-minecraft.git
```

## Primary Dependencies
This repository uses `taskfile` to run installation scripts. If you do not already have it, please install it [here](https://taskfile.dev/docs/installation).

**Proceed to the prerequisites page to continue with the installation process.**
